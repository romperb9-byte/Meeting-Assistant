## មុខងារចម្បងៗ (Key Features)

- 👥 **គ្រប់គ្រងក្រុមប្រជុំ (Meeting Groups):** បង្កើតក្រុមប្រជុំតាមផ្នែក ឬកម្រង និងមានលេខកូដសម្ងាត់ការពារ។
- 📝 **ស្រង់វត្តមាន (Attendance Tracking):** ចុះវត្តមានអ្នកចូលរួមប្រជុំ និងរក្សាទុកនៅលើ Firebase Cloud Database។
- 📄 **ទាញយកជា PDF, Word & Print:** អាចបោះពុម្ព ឬទាញយកជាឯកសារ PDF ស្អាតស្ដង់ដារ A4 និង Microsoft Word (`.doc`) តាមទម្រង់រដ្ឋបាលខ្មែរ។
- 🤖 **បង្កើតកំណត់ហេតុដោយ AI (AI Meeting Minutes):** បង្កើតកំណត់ហេតុអង្គប្រជុំជាផ្លូវការដោយស្វ័យប្រវត្តិដោយប្រើប្រាស់ Gemini AI ជាមួយក្បួនខ្នាតរដ្ឋបាលត្រឹមត្រូវ។
- 📊 **បង្កើតរបាយការណ៍វគ្គបណ្ដុះបណ្ដាល/កម្មវិធី (Training & Program Reports):** បង្កើតរបាយការណ៍លម្អិតតាមគំរូរដ្ឋបាលខ្មែរស្ដង់ដារ (ក្បាលទំព័រ, គោលបំណង, សមាសភាព, ដំណើរការ, ចំណុចខ្លាំង/ខ្សោយ, ដំណោះស្រាយ, ឧបសម្ព័ន្ធរូបភាព និងកន្លែងចុះហត្ថលេខា)។
- 🏛️ **បង្កើតរចនាសម្ព័ន្ធ ឬ អង្គការលេខ (Committee & Org Chart):** រៀបចំគំនូសបំព្រួញអង្គការលេខ និងតារាងសមាសភាពគណៈកម្មការផ្សេងៗ (ឈ្មោះ, តួនាទី, រូបថត, ឋានានុក្រមប្រធាន/អនុប្រធាន/សមាជិក) និងទាញយកជា PDF / Word។
- 📲 **ចែករំលែកងាយស្រួល:** មានភ្ជាប់ QR Code និង Link សម្រាប់ឱ្យអ្នកចូលរួមស្កែនចុះវត្តមានផ្ទាល់ពីទូរស័ព្ទ។

## របៀបដំណើរការនៅលើកុំព្យូទ័រ (Run Locally)

ប្រសិនបើអ្នកចង់បើកដំណើរការនៅលើម៉ាស៊ីនផ្ទាល់ខ្លួន៖

1. **ទាញយកកញ្ចប់កម្មវិធី (Install Dependencies):**
   ```bash
   npm install
   ```

2. **កំណត់ API Key (Optional សម្រាប់ AI):**
   - បង្កើតឯកសារ `.env` (ឬចម្លងពី `.env.example`)
   - ដាក់ `GEMINI_API_KEY=YOUR_API_KEY`

3. **បើកដំណើរការកម្មវិធី (Start Local Server):**
   ```bash
   npm run dev
   ```
   បន្ទាប់មកបើក Browser ទៅកាន់ `http://localhost:3000`
